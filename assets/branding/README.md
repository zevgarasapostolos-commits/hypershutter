# Wigroom — branding

Concept 2A: a bridal bouquet of white roses standing on an editing timeline. The gold bow's knot is the playhead marker and its gold line runs down through the clips.

## Files

| File | Use |
|---|---|
| `hypershutter-mark.svg` / `hypershutter-mark-1024.png` | Mark on white or light backgrounds (transparent PNG) |
| `hypershutter-mark-light.svg` / `hypershutter-mark-light-1024.png` | Mark on slate or dark backgrounds (timeline, stems and wrap in white) |
| `hypershutter-icon.svg` / `hypershutter-icon-1024.png` | macOS app icon, 1024 × 1024 on the standard macOS icon grid (824 px shape, transparent margin) |
| `AppIcon.iconset/` | All macOS icon sizes; build the `.icns` with `iconutil -c icns AppIcon.iconset -o Wigroom.icns` |

## Colours

- Slate `#405366`: timeline, wrap, stems, rose outlines, icon background
- Gold `#A59769`: leaves, bow, playhead (never for text on white: contrast is too low)
- White `#FFFFFF`: roses, backgrounds

## Wordmark

`WIGROOM` in the Apple system font (SF Pro), weight 600, letter-spacing 0.34em, slate. It is set as live text in the app (system font), so there is no font file to ship.
