# A second real wedding: event 070

The sorting on a real wedding that played no part in tuning the rules, on 8 November 2026. Unlike the
first wedding it had never been organized, so it has no folders to compare with. The measure is the
one that matters in daily use: how much of the proposal the videographer had to change.

- **Footage:** 391 clips, 99.5 GB: 270 from the main camera (Sony A7 IV), 58 from the second (Sony
  FX30), 63 from a drone, plus 4 audio files from two recorders.
- **Read-only:** the event folder was fingerprinted before and after (802 entries, sizes and
  modification times): unchanged. The files were not organized.

## Results

| Measure | Result |
|---|---|
| Proposal | 18 folders for 391 clips, 4 clips flagged "needs review" |
| Corrections in Review | none: no clip moved, no folder merged, split or renamed |
| The reviewer's one request | folder names written in Greek instead of Greeklish, a naming preference that does not change the sorting |
| Preparation (scan, clocks, frames, sound) | 28.1 min |
| Sorting (both passes) | 6.1 min |
| Cost | $11.43 (estimated beforehand: $10.12) |

**Clocks.** The second camera was placed 2 min 19 s from the main one from the shared sound. The two
recorders were placed the same way, one of them with file times 806 hours off. The drone has no
sound, so its clock could not be corrected. Most of its clips are stamped 22:00 to 04:12, against
17:13 to 23:40 for the main camera, and 9 of the 63 carry dates from 2023 and 2025. All 63 still went
to the drone folder, because the sorting recognizes the device; only the folder's place in the
numbering is affected.

## What this result does not prove

- "No corrections" means the reviewer accepted the proposal. It is not an independent ground truth,
  the reviewer saw the proposal first, and the reviewer is the author of the system.
- For accuracy against independently organized folders see
  [t2-sound-and-ablation.md](t2-sound-and-ablation.md).
